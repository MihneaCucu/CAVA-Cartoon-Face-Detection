# Dataset setup

The original course datasets are not included in this repository. Obtain them from the course's approved source and place them beside `solutie_fisiere` using the directory names expected by the scripts:

```text
antrenare/
├── daphne/
├── fred/
├── shaggy/
├── velma/
├── task1_gt_antrenare.txt
└── *_annotations.txt
validare/
├── validare/
└── task1_gt_validare.txt
testare/
└── testare/
```

Additional task-specific annotation files may be required for character validation. These directories are ignored by Git so course data and held-out test material are not accidentally published.
